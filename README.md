This is the backend for a smart flashcard system where students can create flashcards, and the system automatically infers the subject based on the content. Students can later request a mixed batch of flashcards grouped by subject.
Add flashcards with automatic subject detection (e.g., “photosynthesis” → Biology).
Retrieve a random set of flashcards across mixed subjects.
Stores flashcards per student.
Simple rule-based subject classification (can be upgraded to ML later).
 Technologies Used

 
Node.js + Express.js

MongoDB + Mongoose

dotenv for config management

CORS enabled for frontend integration
